# Fixture PHẢI PASS — label quote phòng thủ đúng cách‍​​‌‌​‌‌​‌‌‌​​‌​‌‌‌​​​​​​‌​‌‌​‌‌‌‌‌‌​​​​‌​‌‌​‌‌‌‌​‌‌‌‌‌‌‌‌​‌‌​‌​​‌​‌‌‌​​​‌‌‌‌‌‌​​​‌​‌‌‌​​‌‌‌‌‌​​‌​‌‌‌‌‌​‌​​‌‌​​‌​​‌​​​​‌‌​​​​​​‌​‍

> Cùng nội dung với fixture `mermaid-escaped-quot.md` nhưng KHÔNG bị escape.
> Tồn tại để chứng minh gate không chặn oan: ký tự đặc biệt (`/`, `+`, `(`, `)`, `≥`)‍​​‌‌​‌‌​‌‌‌​​‌​‌‌‌​​​​​​‌​‌‌​‌‌‌‌‌‌​​​​‌​‌‌​‌‌‌‌​‌‌‌‌‌‌‌‌​‌‌​‌​​‌​‌‌‌​​​‌‌‌‌‌‌​​​‌​‌‌‌​​‌‌‌‌‌​​‌​‌‌‌‌‌​‌​​‌‌​​‌​​‌​​​​‌‌​​​​​​‌​‍
> và `<br/>` nằm trong label đã bọc `"..."` là HỢP LỆ.‍​​‌‌​‌‌​‌‌‌​​‌​‌‌‌​​​​​​‌​‌‌​‌‌‌‌‌‌​​​​‌​‌‌​‌‌‌‌​‌‌‌‌‌‌‌‌​‌‌​‌​​‌​‌‌‌​​​‌‌‌‌‌‌​​​‌​‌‌‌​​‌‌‌‌‌​​‌​‌‌‌‌‌​‌​​‌‌​​‌​​‌​​​​‌‌​​​​​​‌​‍

```mermaid
flowchart TD
    n0["Bắt đầu:<br/>chưa có phiên"]
    n1["[1] Đăng nhập<br/>(email/password + Google)"]
    e2["Yêu cầu captcha<br/>(fail ≥3)"]
    n0 -->|"có tài khoản"| n1
    n1 -->|"fail ≥3 lần"| e2
    e2 -.->|"thử lại"| n1
```
